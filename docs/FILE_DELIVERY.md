# 文件速递

macOS 菜单栏中的常用文件取用面板，默认启用。设置 → 通用 → 文件速递可开关图标。

## 使用

- 默认入口为下载、桌面；添加本地文件夹或现有收藏夹后，通过顶部标签切换。右键页签选择“删除入口”可移除入口，不删除原文件或收藏夹。
- 面板默认宽 560、高约 396，宽高比为 √2:1，使用主题边框及原生窗口阴影。菜单栏显示 App Logo 的白色主体轮廓，并由系统适配明暗颜色。
- 页签右侧的“＋”下拉提供“添加文件夹”和“添加收藏夹”；前者打开系统目录选择器，后者通过二级菜单选择现有收藏夹。不再提供独立入口管理界面，删除入口直接在页签右键菜单操作。
- 导航区复用主窗口的小尺寸前进／后退／上一级按钮和带边框的面包屑，仅保留视图切换，不显示刷新或面板设置按钮。
- 支持列表／图标视图、多选、双击文件夹浏览、空格或双击文件预览。只允许复制拖出，不提供修改文件操作或拖入。
- 每个入口保存当前浏览位置及滚动锚点；选中文件仅保留到本次进程结束。返回历史在切换入口时重新开始，避免返回到其他标签的目录。
- 原生拖拽进入系统会话并离开面板后收起；目标接受则保持收起，取消或拒绝则恢复。点击外部、Esc 或再次点击菜单栏图标可收起。
- 主窗口关闭后仍驻留；明确退出 App 时释放。没有新增开机启动、全局快捷键、远程目录或压缩包内部浏览。

## 实现与兼容

- `FileDeliveryService` 通过现有设置表保存入口及位置；只在配置键不存在时初始化默认入口，清空后不自动补回。收藏引用继续使用 `IFileTagService`，跟随改名及删除。
- 面板使用单个独立 `FileListViewModel`，复用 `FileListView`、缩略图和导航／加载管线。视图、排序和列宽使用独立设置前缀，主窗口行为不变。
- `IsBrowseOnly` 同时限制菜单加载、鼠标、键盘和修改文件命令；正常列表默认为原有模式。
- 原生 `NSStatusItem` 负责入口和屏幕锚点。面板不调用 `NSApp.activate`，按所在屏幕限制位置及大小，使用浮动窗口层级和跨 Space／全屏辅助窗口行为。
- 拖拽桥接增加会话开始、移动、结束通知；回调上下文持续保留到原生会话结束。文件速递仅传入复制操作标记。
- 面板隐藏时停止当前目录工作和监听，再次显示时刷新。关闭功能时释放面板、独立服务作用域、预览进程和原生事件监听。
