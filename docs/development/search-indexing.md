# 搜索索引的增量写入与调度

搜索继续使用应用自己的 SQLite 索引。FSEvents 负责通知变化，目录枚举及所有索引写入在后台执行；查询使用独立连接。默认搜索覆盖和排除列表保持不变，显式目录与商店目录授权沿用已有逻辑。

## 差异写入与目录删除

`SearchCatalog` 的点／批量写入只更新实际变化的元数据，保留条目 ID。文件名全文索引仅随名称／拼音键变化更新，目录路径全文索引仅随父目录搜索键变化更新。`scan_id` 列保留以兼容现有数据库，但不再作为删除标记，新记录使用空兼容值，不要求重建用户索引。

目录扫描必须使用目录会话：开始时取得旧的直接子项路径，批量记录本轮见到的项，完整枚举并确认仍有访问权后才能提交删除。取消、权限或元数据错误均保留未确认条目；目录删除与其子树清理处于同一事务。路径按 Ordinal / SQLite BINARY 比较，范围判断不能使用未转义的 LIKE。

会话持有该 catalog 的写入串行权，但不跨文件系统枚举持有 SQLite 写事务。仅在短批次中提交新增、更新或删除，搜索读取继续进行。旧成员集合估算限制为 8 MiB；超过后转入 `Logs/scan-scratch` 中的独立临时数据库。临时存储失败时保留旧条目并报告 Partial，不能将失败当作空目录。会话在释放时清理临时文件和成员引用。

## 事件与调度

已知普通文件修改直接检查该文件，同批最多合并 256 项；新增、删除和重命名核对父目录；新目录及需要恢复的子树执行递归扫描。类型未知的事件保守回退目录核对。恢复扫描同时核对其父级，避免只索引子项却遗漏目录本身。

待办按路径去重。非递归目录任务只能覆盖直接子项检查，递归任务才能覆盖后代。每根待办默认最多 4096 项或估算 8 MiB；压力下先扩大到最小共享子树，最后才退化成整根 `OverflowFallback`。

不同根在目录／文件批次边界轮转。用户刷新、覆盖扩大和恢复任务进入高优先级队列。只有溢出导致的整根核对受默认 10 分钟间隔保护；延迟标记和普通待办分开，期间精确更新继续处理。用户刷新、授权／监听恢复、事件日志失效不等待此间隔。

每批待办记录捕获的事件 ID。年轻的高优先级批次完成，不会越过仍在执行的旧批次确认检查点；完整根扫描可以覆盖旧任务，但必须等该扫描结束。扫描期间的新事件保留为后续任务。失败目录保持 Partial，只有成功核对才能清除错误；单文件恢复不得掩盖同目录其他失败条目。

## 诊断和生命周期

状态诊断由单一写入任务原子替换，默认 10 秒合并一次，状态未变化不周期重写。自身数据库、日志和扫描临时文件不进入索引变更处理。统计只增加事件、检查项、条目变更、扫描原因、待办峰值和诊断写入次数，不增加逐文件日志。

延迟、合并和重试间隔统一使用注入的 TimeProvider 和单调时间，诊断时间戳使用 UTC。释放时取消恢复延迟，停止并等待扫描工作者，再补写必要末态并释放监听，不允许退出后重新入队。

## 验证

```bash
bash Tools/Testing/run-tests.sh fast
bash Tools/Testing/run-tests.sh integration --area Search
bash Tools/Testing/run-tests.sh ui --area Search
```

针对测试包含空／中断目录、安全删除、临时集合失败、无变化不更新、记录 ID 与全文索引稳定、路径边界、事件分类、积压合并、恢复优先级、检查点屏障、真实 FSEvents 及诊断自身循环。发行渠道授权另用 `DistributionCommonTests.RevokedGrantStopsExistingIndexWatchAndCanBeReauthorized` 验证。

实际磁盘写入对照见 [SearchWriteBench](../../Tools/Performance/SearchWriteBench/README.md)。逻辑测试、合成数据的进程 I/O 和真实整盘长期验收应分别报告。
