# 首页：最近使用与标签收藏夹

## 基线与范围

目标分支：`feat/list-row-and-hash`
补丁基线：`5f2941a8885da8a550d538c86dcdce2b753d9f24`
仓库 SDK：`.NET 10.0.201`；应用：`net10.0` / `Avalonia 12.0.4` / `osx-arm64`。

首页顶部显示搜索框和主目录／桌面／磁盘三个快捷按钮，分别以液态玻璃包裹，不显示“首页”标题，新增首页工作区，不更换文件列表、标签服务、拖放桥接器或窗口框架。脚本仍然是收藏夹中的普通文件，不增加独立“脚本”分区。

## 交互方案

### 1. 紧凑最近/常用区

首页仅显示“最近使用”，与“收藏夹”使用相同的标题样式，最多显示 8 个文件或文件夹；移除切换、说明文字及标题旁操作按钮。每项是 30 像素文件图标加文件名和添加时间双行文字，路径通过提示显示。最近项区域最多占约两行高度，窄窗中可滚动查看其余项目。

“最近”按最后使用时间排序。历史服务仍保留频率统计（首页不展示），“经常”采用 `log2(次数 + 1) × exp(-距上次使用天数 / 30)`，避免几个月前高频访问的项目永久占据首页。

这是本应用记录的使用历史，不读取或声称覆盖其他应用及操作系统的全局最近文件。记录来自目录导航（包括前进/后退）、应用文件启动服务、进入归档，以及本功能内执行完毕的脚本。仅在其他独立内部编辑入口打开的文件，不保证都经过这些记录点；外部编辑器 CLI/默认打开入口已接入。预览、收藏、排序和列表自动刷新不增加使用次数。

最多保留 500 条历史。首次建表会导入已有 `frequent_folders` 的最近 500 条记录；清空后重启不会再次导入。“清空记录”仅清空首页的 `home_usage`，不删除文件、标签或原有侧栏常用目录记录。不可用路径从最近区过滤，不主动删除磁盘文件。

### 2. 标签就是收藏夹

首页直接通过 `IFileTagService.GetSidebarTagsAsync` 和 `FindFilePathsAsync` 读取既有标签与文件，不另建一套收藏关系。一个文件可出现在多个标签中；标签的 Finder 同步规则继续由原服务管理。

默认显示所有自定义标签和有内容的颜色标签。“空颜色标签”开关可显示空的系统颜色标签。提供新建、重命名、添加文件/文件夹、在文件列表中打开、重置尺寸；文件右键提供“从此收藏夹移除”。添加收藏和移除收藏只调用 `SetTagAsync`，不复制、移动或删除原文件。

本地文件可通过选择器或拖放添加。拖放向系统报告 Copy 是为了避免源位置执行 Move；实际动作仅为添加标签，不复制文件内容。

标签变化会同步刷新首页；标签改名迁移卡片尺寸，删除标签清除其尺寸偏好。与既有侧栏共用数据，但不改变侧栏的现有交互。

### 3. 可缩放大文件夹卡片

默认 `4 列 × 2 行`，最多完整显示 8 个文件，超出时前 7 格显示文件、末格显示组合图标的“展开全部”。支持保存 `2–8 列 × 2–5 行`，每张卡片独立保存，不是首页统一的缩放倍数。

文件格子默认只显示文件图标与文件名。不叠加命令按钮、文件路径、统计数字、Git 状态或脚本专属面板。按可见范围加载与文件列表一致的实际缩略图，未支持的格式回退到文件图标。

右下角是可拖动的行列尺寸手柄；拖动时按格子吸附，结束时保存。手柄聚焦后也可用方向键调整。窗口收窄时按可用宽度临时减少列数，必要时退化为一列；恢复宽度后恢复偏好的列数，不把临时尺寸写回设置。

只有超出容量时，最后一个**物理格子**才显示由多种文件类型图标组成的“展开全部”；未超出时所有格子用于文件。空标签可直接点“添加文件”。

### 4. 展开的收藏夹

点击标题、空白处或溢出入口，以连续展开动画显示居中的启动台式玻璃文件夹。面板保持 3:2 比例并按窗口等比缩小，背后的首页模糊弱化；点击面板外部或 Esc 收回原卡片。

模态视图提供标题、文件图标网格和图标翻页按钮，添加收藏移至右键菜单；支持 Esc 关闭与焦点回归。显示的是同一个标签，文件仍在原位置。图标单击沿用 `FileListViewModel.OpenEntryAsync` 的文件/目录/应用/归档打开逻辑，右键保留脚本命令操作。

为避免大量收藏造成控件和图标堆积，每页最多创建 72 个项目，提供上一页/下一页。没有实现动画式 Launchpad 的手势翻页。

### 5. 脚本命令

在首页卡片、展开收藏夹或最近项中，右键已识别的脚本文件，选择“编辑脚本命令…”。一个文件最多保存 32 条具有不同名称的命令，每条包含：名称、命令内容、Shell 和工作目录。Shell 为 `/bin/zsh`、`/bin/bash`、`/bin/sh`；可在命令中调用自行安装的 Python、Node、Ruby、PowerShell 等解释器。

支持识别 `.sh`、`.bash`、`.zsh`、`.command`、`.py`、`.js`、`.mjs`、`.cjs`、`.ts`、`.rb`、`.pl`、`.php`、`.ps1`、`.lua`、`.fish`、`.scpt`、`.applescript`。扩展名识别不是对脚本内容的安全审计，不自动安装解释器，也不自动信任下载的配置。

例：同一个 `deploy.sh` 可以配置以下两条命令：

```sh
# 名称：部署测试环境
/bin/bash "$SCRIPT" --env staging

# 名称：部署正式环境
/bin/bash "$SCRIPT" --env production
```

右键 → 运行命令 → 选择具体名称，即在 macOS 为 `.command` 文件配置的默认终端中执行对应命令。保存、预览、收藏、刷新均不会运行命令。配置编辑器只编辑执行命令，不修改脚本文件本身。

脚本绝对路径通过环境变量 `SCRIPT` 传递，所在目录通过 `SCRIPT_DIR` 传递；临时启动脚本对路径和命令分别进行 shell 转义。请保留引用变量的双引号。工作目录留空时使用脚本所在目录；可填写本地绝对路径或 `~/...`。继承终端环境的 PATH，并额外包含 `/opt/homebrew/bin` 与 `/usr/local/bin`，命令仍由配置的 Shell 执行。

执行使用普通当前用户权限，不提权。输入、输出、交互和中断均由终端处理，应用不显示执行页面，也不接管命令进程生命周期。

启动文件使用随机名称及仅当前用户可读写执行的权限，通过系统 `open` 交给默认处理程序；开始执行时自行删除，启动失败时由应用清理。应用仅提示是否成功交给终端，不把交接成功视为命令执行成功。

配置绑定文件的绝对路径。同一文件跨标签共用配置；文件物理移动或重命名后，当前实现不会自动追踪并迁移命令配置，需要在新路径重新配置。此变更没有修改普通文件列表原有的全套右键菜单；新增命令菜单作用于上述首页相关入口。

## 视觉实现

使用共享主题资源、原有 `AppWindow` / `DialogWindow` 和统一按钮类。卡片采用 20 像素圆角、轻描边，内部图标项采用更小圆角，标题与内容对齐，浅色/深色由既有动态资源驱动。没有给文件图标叠加浓重玻璃效果，也没有新增大面积装饰性横幅。

这是沿用项目当前 macOS 视觉体系的首页改造；没有另造系统级 Liquid Glass 材质、折射渲染器或替换原生窗口装饰。原有窗口材质能力保持不变。

## 首页玻璃视觉与展开

首页恢复原有白色主题表面；侧栏恢复独立的 `SidebarBackdrop`。`HomeStyles.axaml` 定义共享玻璃、缩略图格与右下角边缘的 Fluent Resize 手柄。卡片标题、空白和溢出末格展开，文件格仍直接打开文件。

`MainWindow.Home` 管理居中的启动台式展开层，背景弱化并模糊，点击外部收回，`HomeFolderTransition` 用位移、缩放和淡入交接完成 320ms 展开／240ms 返回；保留标题栏，隔离底层操作。离开首页、切换标签和关闭窗口时取消展开。

`HomeFileImage` 与展开页共用 `HomeThumbnailCache`，直接复用已解码图片，复用文件列表缩略图服务，按物理像素尺寸请求，限制并发并取消离屏请求；无法生成缩略图时显示共享文件图标。控件只释放自己解码的图片，不释放共享图标缓存。

卡片按完整行列容纳图标，仅项目数量大于栅格容量时，最后一格显示文件类型图标组合的展开入口。`HomeFolderPanel` 按从上到下、从左到右的可用空间自动补位，卡片缩放后重新排列；卡片关闭自身裁切，并为阴影预留外边距。

### 本轮精简与性能回归

展开／收回过程中使用一次采样的玻璃位图，复用变换对象，结束后切换回实时玻璃，避免每帧执行折射和模糊。窗口尺寸变化时重新采样。

本轮 Debug 构建通过，首页回归 32/32；原生窗口确认白色首页、独立侧栏、标题精简、阴影、拖动 Resize 手柄、不同高度卡片自动补位，以及展开和 Esc 收回。未进行帧率量化。

### 图标对齐与展开布局

文件缩略图与溢出入口使用同一固定图标区和文件名行；右上角菜单使用居中的 Fluent MoreHorizontal。展开卡片固定为 3:2，并在小窗口中等比缩小，独立的 `home-expanded-glass` 样式降低背景不透明度以保留玻璃透视。顶部仅显示标题；底部只显示上一页／下一页图标，页码放入提示。文件夹管理操作保留在卡片右键菜单，Esc 和外部点击收回。

### 正方形缩略图与最近使用

缩略图保留原始比例；首页文件项和组合入口的悬停区域固定为 72×72，展开页为 116×116。组合图标使用 48px 正方形区域。展开取消灰色遮罩、整页模糊与标题，并降低玻璃通透程度。最近使用按最后使用排序混排文件与文件夹，双行显示名称和首次加入记录的相对时间；新增 added_at 保存首次加入时间，旧数据使用已有 last_used 补齐，新访问不会覆盖 added_at。

本轮首页回归 41/41，通过首次加入时间保留、文件与文件夹混排、相对时间格式、正方形悬停区域等检查。原生测试使用隔离数据库的图片、文本与目录记录验证双行信息。

最近使用采用 46px 行高、6px 列间距和 2px 行间距，按约 200px 的项目宽度自适应列数，不再限制为三列。

### 全窗口渐变遮罩与首帧修正

展开使用 AppWindow 模板的跨行覆盖层，浅蓝、米白、淡紫渐变覆盖正文、侧栏和顶部标签／工具栏；深色主题使用对应暗色渐变。动画准备完成之前整个展开层透明，底层仅隔离命中测试而不切换禁用样式，避免背景突然变淡；缓存玻璃到实时玻璃使用 80ms 交叉淡入。

### 深色材质与统一圆角

深色首页玻璃和展开玻璃匹配 SidebarAppearance 的深灰材质（表面 #CC30302F、背景采样 0.28、模糊 12），关闭折射、亮边高光、内阴影及外阴影，描边透明。首页卡片、展开页、搜索框及快捷按钮复用侧栏 RadiusLg（10px）。通过样式回归直接对比侧栏参数，防止出现亮边差异。
