# 文件夹渲染与磁盘提示优化验收（2026-11-17）

## 改动边界

本次保留任务开始时的工作区改动和暂存区；基线是修改前工作区构建产物，并非 HEAD 的纯净版本。无公共 API、设置键、用户数据迁移；不修改照片选择顺序、两路合成并发、可见区加载、滚动取消、停留延迟和每列表 16 MiB 成品缓存。

三个独立审查组：

1. **资源内置**：`Assets/FolderArtwork`、`FolderArtwork`、`SvgIconCache`、`FolderCoverPreviewService` 与项目资源清单。两种普通文件夹各 11 个尺寸，四张设置示例中的普通示例复用 256px 图标，另外内置两张照片示例及纸纹，共 25 PNG / 1,161,375 bytes。默认样式保持原路径；资源缺失或解码失败回退默认图标，不执行普通新样式生成器。资源按需解码。
2. **动态渲染优化**：磨砂直接读取／写入 Skia BGRA 预乘缓冲，按实际行步长寻址，取消或异常释放临时原生对象；拟物复用固定纸纹、背板及前片。`FolderMaterialCache` 使用 4 MiB 字节预算 LRU 和租约，淘汰不销毁仍被借用的图像，最后一个借用者释放后销毁；接入原有空闲维护与内存诊断。PNG 返回接口不变。
3. **磁盘提示修复**：`DiskManagementViewModel` 分离查询与操作错误，查询成功不清除弹出失败原因；重试、切换磁盘清除操作错误，选择版本和磁盘身份拒绝迟到结果，关闭后不发布操作通知。

生成、像素检查、基准和长时间循环入口见 [工具说明](../../Tools/Design/FolderRenderAssets/README.md)。原设计演示工具通过友元程序集复用实际渲染器，避免重复编译共享源码；已检查其 Release 构建。

## 性能测量方法

Apple M5 / macOS 27.0.1 / .NET 10.0.201 / osx-arm64；同机 Release，同一测量程序分别加载冻结的旧／新应用程序集。程序集 SHA-256 保存在 `outputs/folder-render-optimization/build-provenance.json`。原生助手复制到可执行文件旁，启动验证 physical footprint 可读，排除默认图标误走 SVG 回退的测量。

每轮均启动新隔离进程，顺序旧→新、新→旧、旧→新。普通图标冷加载尺寸 96px；缓存命中 1000 次；封面在 5 次预热后计时 60 次，112／256px、相同两张已解码图片。记录 P50/P95、当前线程托管分配及各代 GC；进程末尾记录 RSS、physical footprint 和未强制 GC 的托管堆。后者是采样值，不能等同实际存活内存。

滚动基准在真实窗口中使用 10000 项、两路 provider，记录快速跳转和连续滚动的布局及 CPU 离屏绘制耗时。它不是 GPU 呈现 FPS；文件系统枚举不计入该基准。真实应用循环另行覆盖实际目录与页签生命周期。

第一组三轮 `native-*-run*` 与长时间运行重叠，默认样式也出现明显耗时波动，因此保留原始结果但不据此宣称稳定的耗时收益。最终耗时结论使用长时间循环结束后的独立三轮，数据见下文。

## 真实应用 10 分钟生命周期验收

最终 Debug `.app` 经隔离入口启动，实际目录中创建 120 个相册，持续切换三种样式、56／128px 图标、快速滚动与停留加载，并新建／关闭页签。**操作阶段 601.99 秒、201 次循环**；含 65 秒空闲观察及末尾回收检查，总计 667.70 秒，报告成功。

- 60 秒预热后，physical footprint 在 **566.92–594.78 MiB** 间波动，托管堆在 **215.47–254.74 MiB** 间波动，没有随循环次数持续上涨的趋势。本次没有旧版本同长度真应用基线，因此不将这组绝对值解释为整应用内存降幅。
- 材质保留峰值 **1,139,556 bytes（1.09 MiB）**，远低于 4 MiB；各轮采样活动租约均为 0。预热后已关闭对象弱引用存活数为 2–4，没有随 201 次循环累积。
- 空闲后材质从 5 项降为 3 项，共 **1,066,880 bytes（1.02 MiB）**。原有维护机制每 30 秒检查一次、清理超过 1 分钟未使用的项；65 秒观察未覆盖最后一批素材的下一个检查点，因此不声称缓存已全部清空。租约为 0，剩余量是缓存保留；单元回归另验证淘汰、缓存销毁及最后租约释放时原生句柄归零。
- 末尾强制回收前：physical footprint **482.10 MiB**、托管堆 **225.04 MiB**、关闭对象存活 **2**；回收后分别为 **381.35 MiB**、**94.22 MiB**、**0**。强制回收只用于检查存活关系，工作负载期间未强制 GC；不把这个下降作为运行中优化收益。
- 原始 `samples.json`、`retention.json`、`report.json` 保存于 `outputs/folder-render-optimization/soak`。这次记录支持“有界保留且未观察到关闭对象泄漏”，不能替代所有使用时长、目录类型和硬件上的保证。
