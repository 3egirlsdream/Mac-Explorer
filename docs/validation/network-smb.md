# 网络发现与 SMB 系统挂载

支持 macOS 客户端发现 Bonjour `_smb._tcp` 与 WS-Discovery Computer 设备，再由系统 NetFS 挂载 SMB。发现不到的服务器可通过地址连接；不是 Finder 私有网络缓存的镜像，也不依赖旧版 SMB1/NetBIOS 浏览。

网络卷由系统卷元数据识别，挂载路径由系统返回；不假定共享名称对应固定 `/Volumes` 路径。退出和删除配置保留系统挂载，显式弹出使用公开 NSWorkspace API，不强制卸载。原 SFTP 主机信任与传输接口保持。

## 验证边界

本机 SMB2 协议 fixture 不是 Windows、macOS 文件共享或 Linux Samba 真机。未取得三类服务端的专用测试凭据，不将其标记为连接/读写实测通过。商店沙盒的真实挂载及授权仍需在正式签名渠道环境复核；不以官网版或测试替身代替。

重启验收时，界面工具曾额外拉起一个未带测试隔离变量的实例，发现后立即结束；该实例不作为验收证据。后续使用持续终端进程经 `run-isolated.sh` 启动，并核实测试目录与 PID 后再绑定窗口。原有正式应用未结束，专用测试共享及占用/广播进程已清理。

自动用例：`NetworkServiceTests`、`NetworkLifecycleTests`、`NetworkNavigationTests` 及 `DialogSettingsAppearanceTests` 的 SMB 场景。真实应用须通过 `Tools/Testing/run-isolated.sh` 启动新构建包，使用临时配置和专用测试共享。
