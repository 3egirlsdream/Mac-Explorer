# 全局按钮统一验证（2026-11-12）

应用页面、代码动态按钮和插件示例均已检查。应用按钮统一使用 `AppButton` / `AppToggleButton` / `AppSplitButton`，字体、颜色、圆角、边框、内边距、固定高度、悬停／按下／禁用／选中状态及专用角色集中在 `Assets/ButtonStyles.axaml`。页面仅保留内容、行为、状态和布局。

## 范围与实现

- 共享普通操作、危险操作、透明操作、紧凑／小型操作、图标操作、分段选项、分屏布局选择、标签、首页、Copilot、文件任务、表头、面包屑、标题栏、设置和下拉组合等角色；移除页面中的按钮主题与重复外观设置。
- 透明表面共用 `SurfaceButtonTheme`，下拉主按钮与图标入口直接组合现有组件。统一切换按钮的控件属性与实际绘制层，避免 Fluent 的内部选中色覆盖全局主题。
- Markdown 库生成的复制按钮由适配层移除库外观类并接入 `icon-action`，保留原有复制行为。
- 插件宿主加载同一份字体、主题和按钮样式，SDK 示例使用相同变体并保持已发布 API 兼容。框架内部重复按钮、系统授权控件、第三方实现和测试夹具不强制替换类型。
- 检查器接入统一测试入口，检查 XAML／C# 组件入口、局部主题、直接属性覆盖及绑定覆盖。扫描器自身 5 项测试通过。
