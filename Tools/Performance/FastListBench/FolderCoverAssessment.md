# 文件夹照片封面：视觉与滚动性能验收

2026-09-23，macOS arm64，隔离测试配置。封面默认关闭，仅本地图标视图启用。

## 视觉调整

三张照片改为中央略高、左右轻微旋转并错位露出。相片白边和阴影减轻，文件夹前沿覆盖相片下缘并用细线标出开口。真实应用中用三张不同颜色的系统图片检查了浅色和深色主题；相片可辨，图标、文件名与交互区域保持原位置。

## 性能边界

- 滚动期间，每个可见区只保留一个 180ms 等待任务；视口变化就取消。稳定后每隔 18ms 启动一项封面请求，避免每个文件夹各建一个计时任务。
- 扫描和合成在后台执行，最多同时处理两个文件夹。离开可见范围、切换视图或关闭开关会取消待处理请求；切换视图保留已有封面，刷新或重新进入目录才重新核验。关闭状态和列表视图不发起封面请求。
- 解码后的封面复用 FastFileList 的 32 MiB LRU 缓存；112px 封面约 49 KiB。负结果有两分钟重试间隔。

## 复现方法与结果

构建 `Tools/Performance/FastListBench/FastListBench.csproj`，用 `Tools/Testing/run-isolated.sh` 启动打包的 `FastListBench.app/Contents/MacOS/FastListBench <输出目录> --folder-cover-only`。基准先预热，再对 10,000 个合成文件夹测关闭、开启、再次关闭。每种状态包含 120 次快速跳转、24 次 250ms 停留和 180 次小步连续滚动；计时包含 Avalonia/Skia 的滚动定位和 CPU 光栅绘制。数据位于隔离输出目录的 `folder-cover-comparison.json`。

| 独立运行 | 快速滚动 p95：关闭 / 开启 / 再关 | 连续滚动 p95：关闭 / 开启 / 再关 | 48 项视口调度 p95：关闭 / 开启 |
| --- | ---: | ---: | ---: |
| 1 | 3.72 / 3.68 / 3.24 ms | 3.82 / 2.93 / 3.45 ms | 17.0 / 15.6 μs |
| 2 | 2.95 / 2.99 / 3.63 ms | 3.86 / 3.12 / 3.02 ms | 17.0 / 23.0 μs |

两次关闭状态均发起 0 个封面请求，开启状态分别发起 182 个；快速换视口的回归测试确认不会为每个经过的文件夹排队。此前逐文件夹计时的版本曾出现 10.67ms 的快速滚动 p95，因此改为单个视口等待任务。最终两轮没有重复出现开启状态的 p95 回退。

另以 1,000 个本地直接子文件、缓存中的 112px 图片字节测扫描与合成：扫描 p95 为 0.86–1.32ms；扫描加合成 p95 为 1.65–1.85ms。该成本在后台执行，最多两个并发。

这些数值不含原生 Quick Look 冷生成、GPU 呈现帧率、慢盘和极大目录的扫描。大目录仍必须遍历直接子文件才能选出按文件名排序的前三张；取消检查在遍历过程中进行。当前证据支持“正常本地目录的快速滚动未观察到稳定回退”，不等于所有磁盘与图片格式下绝对零开销。
