【购买说明】
下载应用不包含永久免费使用权。本商店版的全部文件管理功能均需通过 App 内购买的年度自动续订订阅解锁。没有有效订阅或试用权益时，文件管理功能将被锁定。以下介绍的功能均包含在年度订阅内。

文件资源管理器是为 macOS 打造的多工作区文件管理器，将文件浏览、搜索、预览、整理与传输集中在一个窗口中。

多标签与分屏
使用多标签、横向或纵向分屏及四宫格，同时查看多个目录。每个标签独立保留导航历史、排序和视图，通过面包屑与路径输入快速跳转。

视图、收藏与嵌套标签
在列表、网格和树形列表间切换，按类型、日期或大小筛选和分组。通过收藏夹与嵌套标签整理文件，快速定位原文件，文件保留在原位置。

搜索与文档预览
搜索已授权目录中的文件，利用已生成的 OCR 文本和图片分析结果查找内容。按空格预览图片、PDF、文本及系统支持的文档；Command-K 搜索支持随选中结果更新的侧边预览。PDF 支持按宽度适配的连续阅读，Office 文档通过系统 Quick Look 预览。

批量重命名
组合替换、编号、日期与名称模板，逐步预览名称变化并检查冲突。支持保存预设与整批撤销。

统一任务管理
在紧凑任务面板中查看复制、移动、删除、压缩、解压及 SFTP 传输的状态与进度，按任务类型暂停、继续、取消或重试。队列和撤销记录保留在当前应用进程内。

压缩包浏览与解压
浏览、预览和解压 ZIP、7z、RAR、TAR 及多种压缩格式，创建 ZIP 等压缩包。具体支持范围取决于格式、压缩算法、加密与分卷方式。

网络、SMB 与 SFTP
在网络页面查看发现的服务器、保存连接和系统已挂载网络卷。通过 macOS 系统挂载 SMB 共享，或使用 SFTP 浏览、上传、下载与管理远程文件。

设备间传输与拖放
使用 LocalSend 协议与可达网络中的兼容设备传输文件，或通过系统隔空投送发送文件。支持从微信拖入文件和图片；系统限制读取时可授权附件所在文件夹，授权后继续保存并在下次使用时复用。

照片整理与菜单栏文件速递
使用设备端图片分析识别图中文字、人脸和场景，结合照片元数据辅助整理；照片地点名称解析为可选联网功能。通过菜单栏文件速递面板浏览常用目录和收藏夹，预览或拖出文件副本。

可选 Copilot 文件助手
通过自然语言协助查找与整理文件。需自行配置兼容的模型服务、模型名称及 API Key，第三方服务可能收费。首次连接模型服务会请求许可；修改文件或向模型发送文件正文前会显示确认计划。

为 macOS 日常使用设计
支持浅色与深色主题、自定义快捷键，以及简体中文、繁体中文、英文和法语界面。改进按需加载、任务进度刷新与闲置缓存清理，减少长时间使用的资源累积。

访问范围由你决定
商店版通过系统选择器获取文件或文件夹授权，并支持在设置中撤销。配置、索引与对话历史保存在本机；可选联网功能按用户设置和授权运行。

适用于 Apple Silicon Mac，需要 macOS 14.0 或更新版本。具体预览格式取决于系统支持情况。
