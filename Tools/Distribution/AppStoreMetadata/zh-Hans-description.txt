文件资源管理器是为 macOS 打造的多工作区文件管理器，将浏览、查找、预览、整理与传输集中在一个窗口中。

【功能介绍】
1. 多窗口工作区支持多标签独立导航、拖动排序、批量关闭及启动恢复，提供横向、纵向、三窗格、四窗格与主次分栏布局。
2. 路径导航支持面包屑、子目录菜单、地址输入、前进后退和上级目录，侧栏集中访问常用位置、置顶目录、本机磁盘与已挂载位置。
3. 文件浏览支持列表、图标网格和树形视图，提供列筛选、排序、分组、文件与文件夹优先规则、缩略图及照片文件夹封面。
4. 信息面板展示路径、类型、日期、大小、图片尺寸及照片元数据，支持目录大小统计、SHA-256 计算、标签搜索和文件评分。
5. 文件管理支持新建、复制、剪切、移动、重命名、拖放、粘贴图片、选择打开方式、复制路径及移到废纸篓，并可撤销受支持的操作。
6. 后台任务集中展示复制、移动、压缩、解压和传输进度，支持并行执行、暂停、继续、取消及失败重试。
7. 批量重命名支持替换、正则表达式、插入、删除、大小写、清理、编号、日期、模板和扩展名规则，可调整步骤、保存预设、对比名称、检查冲突及整批撤销。
8. 首页展示最近文件、常用位置和收藏夹，支持调整收藏网格大小、展开浏览及主目录、桌面、磁盘快捷访问。
9. 收藏与嵌套标签支持分层管理、重命名、子标签、颜色别名和文件归集，配合星级评分整理资料，收藏和标签保持原文件位置。
10. 搜索支持当前目录、全局文件名、PDF 正文和图片 OCR 内容，提供搜索范围设置、热门文字、结果预览及所在目录定位。
11. 本机图片分析支持人物识别与命名、场景分类、文字识别、拍摄日期和地点浏览，可独立控制自动分析及照片地点解析。
12. 空格预览支持图片、RAW、PDF、Office、文本、媒体、文件夹和压缩包，提供 PDF 连续页面、嵌套内容浏览及 Markdown 编辑与渲染预览。
13. 压缩管理支持浏览和解压 ZIP、TAR、7Z 等格式，创建 ZIP、TAR.GZ、TAR.BZ2 压缩包，并支持加密 ZIP。
14. 文件转换支持 Markdown 与文本转 Word 或 PDF、Word 转 PDF，以及 SVG、ICO、ICNS、WebP 转 PNG 或 JPG，并可设置输出图片尺寸。
15. 网络管理支持 SFTP、SMB、WebDAV 和系统网络卷，提供服务器发现、连接保存、密码或私钥认证、主机指纹确认、挂载弹出、远程文件传输及 SFTP 编辑回传。
16. 文件分享支持 LocalSend 设备发现、跨网段与 IP 直连、发送和接收文件及文件夹，并提供 macOS 隔空投送入口。
17. 菜单栏文件速递支持目录与收藏夹页签、路径导航、文件预览和复制拖出，固定暂存页签可临时归集路径并清空暂存内容。
18. Copilot 文件助手支持自定义模型服务、自然语言检索、文件属性筛选、整理与重命名方案、文件转换、内容总结、路径附件、会话历史及自定义技能。
19. 外观设置支持浅色与深色、九款背景主题、自定义图片与配色、透明度、交互颜色和排版密度；提供简体中文、繁体中文、英文、法语、自定义快捷键及 Cmd 快捷提示。
20. 通过系统选择器授权文件夹，并在设置中管理访问范围；文件访问与搜索限定在已授权目录，配置、索引与会话历史保存在本机。
21. 更新服务支持启动自动检查、手动检查和更新说明，发现新版后可前往 App Store 更新；关于页提供隐私政策、问题反馈、反馈群及商店评分入口。
