【购买说明】
下载应用不包含永久免费使用权。本商店版的全部文件管理功能均需通过 App 内购买的年度自动续订订阅解锁。没有有效订阅或试用权益时，文件管理功能将被锁定。以下介绍的功能均包含在年度订阅内。

文件资源管理器是为 macOS 打造的多工作区文件管理器，将浏览、搜索、预览与整理集中在一个窗口中。

并排浏览，减少来回切换
使用多标签与横向、纵向或四宫格分屏，同时查看多个目录。每个标签独立保留导航历史、排序和视图，配合面包屑与路径输入快速跳转。

多种视图，清晰整理
在列表、网格和树形列表之间切换，按类型、日期或大小筛选和分组。使用 Finder 标签整理文件，文件保留在原位置。

快速搜索，即时预览
搜索已授权目录中的文件，并利用已生成的 OCR 文本和图片分析结果查找内容。按空格预览图片、PDF、文本及系统支持的文档；在搜索结果旁直接查看预览。

批量重命名
组合替换、编号、日期和名称模板，逐步预览名称变化，检查冲突后再执行。支持保存预设及整批撤销。

压缩包与远程文件
浏览和解压常见压缩格式，创建 ZIP 等压缩包。通过 SFTP 浏览、上传、下载和管理远程文件，通过 LocalSend 协议与局域网中的兼容设备传输文件。

照片与文档整理
使用设备端图片分析识别图中文字、人脸和场景，结合照片元数据辅助整理。照片地点名称解析为可选联网功能。

可选 Copilot 文件助手
使用自然语言协助查找与整理文件。需自行配置兼容的模型服务、模型名称及 API Key，第三方服务可能收费。首次连接模型服务会请求许可；修改文件或向模型发送文件正文前会显示确认计划。

适合 macOS 的日常操作
支持浅色与深色主题、拖放、自定义快捷键和菜单栏文件速递面板，方便访问常用目录并拖出文件副本。

访问范围由你决定
Mac App Store 版本通过系统选择器获取文件或文件夹访问授权，并支持在设置中撤销。应用配置、索引及对话历史保存在本机；可选联网功能按用户设置和授权运行。

本版本适用于 Apple Silicon Mac，需要 macOS 14.0 或更新版本。具体预览格式取决于系统支持情况。
