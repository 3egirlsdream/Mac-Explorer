# App Store 年度订阅

只在 `DistributionChannel=AppStore` 启用。客户端调用 Apple StoreKit 2，验证签名交易，不需要自建服务器或在应用内存放 App Store Server API 密钥。

当前商店 Bundle ID 为 `com.thankful.top.macexplorer.store`，年度订阅商品 ID 为字符串 `001`（保留前导零）。商店构建默认使用这两个值；测试可通过 MSBuild 参数覆盖，正式提审会核对 `release-config.json`。Apple 后台显示的数字 Apple ID 不参与 StoreKit 商品查询。

## Apple 后台配置

1. 在正式应用中建立一个订阅组，添加唯一的自动续订商品，周期一年。商品 ID 不可随版本改变。
2. 中国大陆目标价格为人民币 ¥9.9/年。先在 App Store Connect 确认可选价格点；如果没有这一价格点，重新确认价格，不擅自选取相近价格。其他地区配置本地价格。
3. 发布分级付费版本前，在 App Store Connect 移除面向新用户的免费试用介绍优惠，保留已有订阅及已开始的 Apple 试用。应用自行提供首次进入后连续 168 小时免订阅体验，不自动扣费。桥接仍如实显示 StoreKit 返回的实际优惠；后台未修改时不得宣称已取消 Apple 优惠。
4. 完成付费应用协议、税务、银行账户、销售地区、订阅本地化、审核截图及说明。使用 Apple 标准 EULA，在商店描述中提供条款及隐私政策链接。
5. 将实际 Bundle ID 和商品 ID 填入同目录 `release-config.json` 的 `appStoreBundleIdentifier`、`appStoreSubscriptionProductId`。构建同时传入相同的 `AppStoreBundleId`、`AppStoreSubscriptionProductId`，正式提交加 `StoreSubmission=true`。缺少或不匹配的配置会拒绝提审构建。
6. 首个订阅商品与应用版本一起提交审核。这里的构建和检查不创建商品、不上传、不提交审核。

## 运行规则

- 官网版不启用本机制；第三方插件的试用和授权独立处理。商店版的功能矩阵见 [功能权限](../../docs/distribution/feature-access.md)。
- 首次主界面可用后创建连续 168 小时体验记录，无需订阅。记录保存在现有 SQLite `app_settings`，使用事务初始化，不随重启或升级重置；写入失败明确提示，基础功能继续可用。
- Apple 权益与应用体验分别管理。已验证的有效订阅／Apple 试用继续解锁；已识别的订阅用户不积存额外体验。退款或成功返回空权益立即清除 Apple 权限，仍按独立应用体验记录判断。
- `FeatureAccessService` 维护共享内存权限快照，查询无锁、无分配、无 I/O。启动、到期、前台恢复和交易变化时刷新；首次价格查询不阻断应用体验。
- 不再自动覆盖所有窗口；高级入口按需显示可关闭订阅页。免费保留本地文件操作、多页签、预览、收藏、标签、普通搜索、已挂载目录和任务控制。
- 新高级操作在入口检查；已接受任务继续执行和恢复，失败后重新发起需重新检查。任务检查点不查询订阅，不主动卸载卷或删除配置。
- 背景到期恢复默认，保存用户的图片、配色与启用意图；重新解锁自动恢复，主动关闭则不恢复。文件速递拒绝新增操作，保留暂存路径和偏好，允许清空。
- 现有 StoreKit 验证仍每 15 分钟、前台恢复、交易变化及订阅到期时执行；有效权益在验证失败时保留至原到期，不增加本地订阅宽限期。商品查询失败只影响购买入口。
- `AppStore.sync()` 仅用于用户主动恢复购买。购买取消或待批准不授予 Apple 权益；有效应用体验不受影响。

## 验收清单

- 在 Apple Sandbox 测试应用免订阅体验、无介绍优惠的新订阅、已有 Apple 试用、购买取消、Ask to Buy 待批准、自动续费、关闭续订、到期、退款、恢复购买、换设备和离线。
- Sandbox 时间经过加速，按 Sandbox 实际续费周期验证到期事件，不等待真实一年。
- 使用 `bash Tools/Testing/run-isolated.sh <新构建应用的 Contents/MacOS/MacExplorer>`，不复用正常实例及真实目录。构建传 `-p:SkipMacOSReleaseDMG=true`。
- 检查浅色、深色、窄窗口、多个窗口、文件速递、已打开的菜单与快捷键；验证升级页可关闭且可键盘操作；到期后基础任务可继续发起，高级新任务受限，已接受任务安全完成。
- 商品展示必须与 Apple 付款确认页的本地价格和优惠一致。缺少商品或验证失败时应能重试、恢复购买、管理订阅、打开隐私／条款和退出。
- 测量原版本和接入版本的首帧时间；本地构建／替身测试通过不等于 Apple Sandbox 支付通过或正式审核通过。
