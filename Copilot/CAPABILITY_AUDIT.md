# Copilot 能力接入清单

`AppCapabilityRegistry` 当前登记 75 个内置稳定 ID，并为已安装插件的命令动态生成 `plugin.command:` ID。目录记录参数、原逻辑归属、影响级别和确认规则；模型通过查询目录按需发现能力。

| 功能区 | 已接入的共用入口 | 尚未接入能力目录的用户操作 |
| --- | --- | --- |
| 文件与搜索 | 列表、信息、搜索、正文提取、生成文本、单项及批量重命名、移动、复制、删除、评分 | 剪切板复制/粘贴、打开方式、复制路径、系统 Finder/终端打开、废纸篓清倒/恢复、撤销 |
| 导航与预览 | 位置、首页、前后/上级、新标签/窗口、窗格布局、刷新、视图、排序/分组、预览和信息面板 | 标签关闭/切换、部分全局搜索及列筛选操作 |
| 标签与收藏 | 标签查询/创建/改名/删除/固定/颜色/应用，收藏文件夹查询/固定/取消 | 首页收藏夹的布局编辑 |
| 压缩与转换 | 压缩包列表与解压、原有压缩配置窗口、动态插件转换命令 | 由 Copilot 直接填写压缩格式与参数 |
| 插件 | 安装列表、市场查询、本地与市场安装、启停、卸载、恢复、取消 | 插件配置界面的专用参数编辑 |
| SFTP | 保存连接查询、连接/断开、现有连接窗口；常规文件操作沿用原有远程实现 | 保存连接的增删改、专用远程传输管理 |
| 设置、脚本、文件速递 | 常用显示设置与主题、已有脚本查询/运行、文件速递位置与开关 | 其余设置项、脚本命令编辑、应用更新安装 |

界面共用入口已覆盖工具栏中的导航/视图/排序/分组/信息面板、标题栏中的新标签/窗格布局/设置、命令搜索及插件命令。其他菜单和快捷键尚未全部改走能力入口。后续接入应继续复用现有操作服务和窗口，不为 Copilot 复制业务逻辑。
