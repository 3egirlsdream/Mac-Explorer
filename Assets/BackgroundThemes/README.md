# QQ 开发主题素材

由用户提供并指定用于本分支开发。三份纹理保持原始字节，来源、SHA-256 与 QQ 原始参数见 sources.json。

粉墨都市、霓虹灯光、香芋啵啵使用官方预览内嵌渐变的角点颜色作为参考，浅／深色配色为 Mac Explorer 的文字可读性做了调整。天青色为以 QQ 配色为参考的无纹理渐变。红消绿冷以 QQ 配置中的四个背景颜色为基础，浅色混入白色以保证次级文字可读，深色沿用原 alpha 配色；PNG 自带 alpha 保持不变。此处的四角渐变、布局和混合方式是本程序的明确实现，不宣称复刻 QQ 未提供的渲染算法或枚举含义。

资源随应用打包；运行时不读取 Downloads、QQ 安装目录或下载网络文件。SVG 仅从这些固定资源载入并限制栅格尺寸；自定义图片继续使用受限的 PNG/JPEG/WebP 解码。

标题栏空白区使用当前浅／深色配色顶部的无纹理渐变，激活页签仍接续正文原图。自定义图片从同一合成图的轻模糊缓存上部按左／中／右区域取均色生成渐变。此处借鉴配色与纹理分层；QQ 安装资源的样式正文不是可直接读取的明文，未确认其标题栏精确算法。
