## 比例与拼接

原 SVG 的单元保持 650×650；精品 PNG 保持原始 2000×1969／1970 的比例。宽幅 SVG 连续排布三个原比例单元；精品与动物迷彩系列使用四个相邻镜像单元，让每个接缝两侧取到相同边缘，不用透明竖条掩盖接缝。图案不横向拉伸。画布约为 3:1／4.06:1，首尾仍可继续平铺；内部图案本身会按原有节奏重复。

运行时始终按背景区域高度等比缩放，再横向重复；也可选择铺满裁切。色彩渐变覆盖整个窗口，不随图案单元重复。默认强度 35%，只调整图案，不改变底色。背景不随列表滚动。

所有预置文件只含矢量路径、形状与引用，没有 `<image>`、Base64 位图或外部资源。原 PNG 的矢量化会平滑颗粒、简化细节，并非无损复制；保留了完整构图、颜色与分层透明度。设计输入与生成文件的 SHA-256 记录在 `sources.json`。这些素材为用户提供的 QQ 参考改作，不另行声称公版或按代码许可证授权。

## 生成与运行

`Tools/Design/generate-theme-vectors.py <原始背景纹理目录>` 可重建九款素材。设计工具依赖 Python 3.12、Pillow 13.0.0、vtracer 0.6.15，应用运行时不依赖 Python、不联网，也不读取 Downloads。

矢量源只在切换时栅格化一次，缓存上限为 4096×1280（20 MiB），兼顾宽画布的纵向细节。用户导入图片仍由 `BoundedImageDecoder` 限制到最长边 2048px。窗口缩放仅重建最长边 2048px 的清晰合成与最长边 1024px 的磨砂合成，不重新解码素材。

沿用窗口共享坐标：激活页签与正文连续，状态栏保留清晰纹理；导航、工具栏和信息面板显示同一合成结果的轻磨砂。标题栏从合成图上部取宽区域均色，显示无纹理渐变。弹窗保持原样。设置切换保留自定义图片，旧开发预置 ID 自动迁移，关闭主题恢复默认表面。

## 验证

`bash Tools/Testing/run-tests.sh fast` 和 `ui`；原生截图通过 `MACEXPLORER_BACKGROUND_THEME_SMOKE=1 bash Tools/Testing/run-isolated.sh <Debug可执行文件>`。检查九款 SVG 不含位图、原始比例延续、实际 SVG 渲染首尾接缝与平铺几何、浅深色文字对比度、四语设置切换、自定义图片恢复，以及页签、磨砂与原图的坐标连续性。

## 独立配色

`BackgroundThemeOptions.Colors` 按图案保存配色 ID 与自选颜色，旧设置默认沿用原配色。自选颜色按浅／深模式生成协调的明暗色阶；切换图案会记住各自的颜色。调色不重新解码 SVG，实时更新主窗口、清晰／磨砂及标题栏的统一合成，预览复用同一渲染代码。设置预览源限制为 384×128，每格为 180×100，后台顺序加载，关闭设置释放。自定义图片通过顶部图片按钮恢复，保留原文件和图案配色记录。

主题取色卡和设置中的交互颜色复用 `ColorPalette`：推荐色按钮、当前选色、恢复默认和十六进制输入；修复色块尺寸为零的显示问题。手动输入在回车或失焦后应用，Esc 撤销草稿；主题使用 RGB，交互颜色保留 ARGB 支持。
